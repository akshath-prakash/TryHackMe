# Search Skills

## Overview

This TryHackMe room focused on using the Internet and specialized services to gather cybersecurity information efficiently.

Security professionals often need to find technical documentation, research vulnerabilities, investigate indicators, understand tools, and track current threats. Knowing where and how to search is an important cybersecurity skill.

## Skills Demonstrated

- Cybersecurity research
- Internet search techniques
- Technical documentation lookup
- Vulnerability research
- Threat intelligence gathering
- Evaluating online security resources

## Tools and Services Used

| Tool or Service | Use Case |
| --- | --- |
| **GitHub** | Search source code, security research, documentation, and proof-of-concept repositories |
| **Shodan** | Find information about Internet-connected devices and services |
| **VirusTotal** | Research files, URLs, domains, IP addresses, and malware-related indicators |

## Research Process

### GitHub

GitHub can be used to search for technical documentation, security tools, vulnerability research, and repositories related to a specific topic or vulnerability identifier.

During the room, I practiced using a vulnerability identifier as a search term and reviewing the available repository information, including the repository name, description, programming language, and activity.

When reviewing security-related repositories, it is important to check the source, understand the purpose of the code, and only test tools in an authorized lab environment.

### Shodan

Shodan is a search engine for Internet-connected devices and services. It can help security professionals understand what services are exposed and gather information for defensive assessments.

Shodan should be used responsibly and only for authorized research and security testing.

### VirusTotal

VirusTotal can be used to research suspicious files, URLs, domains, and IP addresses. It combines results from multiple security tools and can help analysts identify potential malicious activity.

The results should be treated as supporting evidence and verified with additional reliable sources.

## Important Findings

- Cybersecurity research often requires using multiple specialized services.
- GitHub can provide technical documentation and security research.
- Shodan can provide information about exposed Internet services.
- VirusTotal can help investigate suspicious indicators.
- Search results should be evaluated carefully because online information may be incomplete, outdated, or inaccurate.
- Tools and proof-of-concept code should only be used in authorized environments.

## Key Takeaway

Effective searching is an important skill in cybersecurity. Finding the right information quickly can help analysts investigate threats, understand vulnerabilities, identify indicators of compromise, and make better security decisions.

## Conclusion

This room introduced several websites and services that can support both offensive and defensive cybersecurity work. Learning how to search these resources efficiently is just as important as learning how to use the tools themselves.
